# 参照資料フォルダ（reference/）

このフォルダに資料を置くと、Claudeがスライドを作成する際に参照します。

## 置くと効果的なファイル

| ファイル例 | 用途 |
|-----------|------|
| `自己紹介.md` | スライドの自己紹介スライドに使用 |
| `ターゲット像.md` | 訴求内容・トーンの調整 |
| `実績・受講生の声.md` | 成果スライドの数字・コメント |
| `過去セミナーPDF/*.pdf` | スライド構成・テーマの参考 |
| `キーワード集.txt` | よく使う訴求ワード・スローガン |
| `AIセラ_ブランドガイド.md` | 色・フォント・文体のルール |

## フォーマット

`.md`, `.txt`, `.pdf`, `.pptx` いずれも可。
Claude が自動で読み込みます（Coworkセッション開始時）。

## 例：自己紹介.md の書き方

```markdown
# プロフィール

- エンジニア歴：10年以上
- 副業収入：月収100万円達成
- 指導実績：1,000人以上
- 得意領域：AI×自動化、Claude Code、SNS自動化

## 実績
- 2ヶ月で月収200万円達成の受講生輩出
- AIコミュニティ運営（メンバー500名以上）
```

---

このフォルダは空でも動作します。
資料があるほどスライドの質が上がります。
